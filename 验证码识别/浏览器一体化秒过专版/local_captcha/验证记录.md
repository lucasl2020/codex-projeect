## 运行方式

```powershell
# 1. 启动本地模型服务（窗口可最小化后台运行）
.\启动本地模型.ps1

# 2. 环境检查
python -m local_captcha --doctor

# 3. 执行福利站验证（自动复用 output/local-session.json，并自动提交）
python -m local_captcha https://checkin.new-api.abrdns.com/level --submit "button.level-verify-submit" --success-selector ".level-verify-submit"

# 4. 执行 Hvoy 验证
python -m local_captcha https://www.hvoy.ai/
```
