# 🛡️ 本地离线验证码助手 - 浏览器一体化专版

> **用户感知**：平时正常打开 Chrome 上网，右上角只有一个轻量小盾牌图标；打开包含 Google reCAPTCHA、Cloudflare 或 hCaptcha 的网页时，插件瞬间向本机静默服务通讯，直接自动打勾或自动点击秒过，体验上完全一体化！

---

## ⚡ 三步极速上手

### 1. 启动与加载
双击运行：
👉 **`一键安装并秒启动.bat`**
- 自动后台静默拉起离线视觉模型与桥接服务（**完全无 CMD 黑色窗口**）；
- 自动启动 Chrome 并注入扩展。

### 2. 固定图标
在 Chrome 浏览器右上角点击“扩展程序”（拼图图标），点击本插件右侧的 **📌 图钉**，将其固定在浏览器顶部工具栏。

### 3. 日常无感畅游
像平时一样正常上网浏览即可。遇到验证码时：
- 插件图标闪烁绿色 **`✓`** 徽标；
- 复选框自动勾选，图片挑战自动由本地离线大模型计算作答；
- 点击插件图标可查看 **`⚡ 累计自动秒过：X 次`**。

## 🛠️ 工具脚本一览

| 脚本 | 作用 |
| :--- | :--- |
| `一键安装并秒启动.bat` | 一键静默启动后台并打开 Chrome 装载扩展 |
| `启动后台静默服务(无黑框).vbs` | 纯静默启动后台服务（不打开浏览器） |
| `设为开机静默自启(推荐).bat` | 将静默服务设为 Windows 开机自启，平时开机即用 |
| `取消开机自启.bat` | 移除开机自启动项 |
| `服务状态一键检测.bat` | 一键检测后台模型与桥接网关是否在线 |
| `停止后台服务.bat` | 一键彻底关闭后台服务 |

## 🔒 隐私与安全性
- **100% 离线本地**：大模型权重（Qwen3-VL:4b）直接运行在本机显卡/CPU，零数据上传外部云端。
- **纯内网通信**：浏览器扩展与后台服务仅通过 `http://127.0.0.1:8765` 通信，不产生任何外网流量。
