# 浏览器扩展一键安装与使用指南

本扩展（**本地离线验证码自动通过 / Local Captcha Auto-Pass**）可在日常使用 Chrome / Edge 浏览器上网时，自动嗅探并秒过 **Google reCAPTCHA**、**hCaptcha** 与 **Cloudflare Turnstile** 验证码。

---

## ⚡ 方式一：Windows 一键启动（最推荐，零配置）

在项目根目录下，直接双击运行：

👉 **`一键安装与启动.bat`**

**该脚本全自动执行以下流程：**
1. 检查 Python 环境；
2. 确保后台离线大模型（Ollama + `qwen3-vl:4b`）静默就绪；
3. 启动本地扩展桥接服务（`127.0.0.1:8765`）；
4. **自动拉起 Google Chrome 并自动装载本插件**！

拉起浏览器后，右上角即可看到扩展图标。

---

## 🛠️ 方式二：手动导入安装（现有日常浏览器）

如果你想在日常一直使用的 Chrome 或 Edge 浏览器中长期启用该扩展：

### 1. 确保后台服务已启动
在项目根目录运行一次一键启动脚本：
```powershell
.\启动本地模型.ps1
python local_bridge.py
```
*(可最小化窗口在后台静默运行)*

### 2. 在浏览器中加载扩展
1. 打开 Google Chrome 或 Edge 浏览器；
2. 在地址栏输入 `chrome://extensions/`（Edge 输入 `edge://extensions/`）并按回车；
3. 打开右上角的 **【开发者模式】(Developer mode)** 开关；
4. 点击左上角的 **【加载已解压的扩展程序】(Load unpacked)**；
5. 在弹出的文件选择框中，选择本项目下的 **`chrome_extension`** 文件夹（即 `D:\codex-projeect\验证码识别\chrome_extension`）；
6. 导入成功！浏览器工具栏将出现 **🛡️ 本地验证码助手** 图标。

---

## 🎛️ 扩展控制面板功能

点击浏览器右上角扩展图标，将弹出精简控制面板：

- **模型连接状态**：
  - 🟢 **模型在线**：本地后台已连通，处于随时待命状态。
  - ⚪ **模型未启动**：若显示未启动，请运行 `一键安装与启动.bat` 即可拉起。
- **功能独立开关**：
  - **总开关**：一键启用 / 暂停全局自动化。
  - **Google reCAPTCHA**：开启后自动模拟点击复选框实现免挑战秒过 (No-CAPTCHA)，遇图片自动提交本地模型作答。
  - **hCaptcha 空间画布**：开启后自动执行 3D 拼块平滑拖动与多点点击。
  - **Cloudflare Turnstile**：开启后自动识别并点击 5 秒盾勾选框。

---

## 📦 打包与分发至其他电脑

如果你需要将扩展分享给其他电脑或同事使用：
1. 运行根目录下的 `.\一键打包发布.ps1`；
2. 脚本会在 `output/` 目录下生成 **`local_captcha_extension.zip`**（体积仅约 7 KB）；
3. 对方解压后，在浏览器的 `chrome://extensions/` 中【加载已解压的扩展程序】即可直接使用。
