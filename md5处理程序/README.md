# CSV 手机号转 MD5 与数据清洗工具集

高性能 CSV 流式数据清洗与脱敏工具，支持 **图形化界面 (GUI)** 与 **命令行 (CLI)** 双模式运行。具备多进程并行加速、内存低占用流式读取能力，轻松应对百万级至千万级超大 CSV 文件。

---

## 🌟 核心功能

1. **手机号转 MD5**：自动识别并提取各列中的大陆 11 位手机号（自动剔除 `+86`、空格、横杠等杂质），转换为标准 32 位小写 MD5 哈希值，其余列数据原样保留。
2. **删除手机号行**：检测到含有未脱敏明文手机号的行直接过滤剔除，仅保留安全数据。
3. **按 MD5 去重**：流式统计已出现的 MD5 键值，剔除重复数据行。
4. **按手机号去重**：按原始手机号维度去重。
5. **双操作形态**：
   - **GUI 界面**：支持拖拽选文件、进度条实时反馈、日志实时查看，小白友好。
   - **CLI 命令行**：支持自动化批处理、多进程 Worker 调节、静默输出。

## 🖥️ 使用方式

### 方式 1：双击图形界面（最推荐 ⭐⭐⭐⭐⭐）

直接双击运行：
👉 **`csv_phone_to_md5_gui.pyw`**

或在打包好的发布版中双击：
👉 **`release\md5处理程序\csv_phone_to_md5_gui.exe`**

#### GUI 操作步骤：
1. 点击“浏览文件”或直接将 CSV 拖入输入框。
2. 选择处理模式（手机号转 MD5 / 删除手机号行 / 按 MD5 去重 / 按手机号去重）。
3. 选择目标列（支持“自动识别全部列”或指定某一列）。
4. 点击“开始处理”，下方控制台将实时显示处理行数、转换速率与耗时。

---

### 方式 2：命令行调用 (CLI)

#### 基础用法：
```bash
# 手机号转 MD5（默认模式，自动生成 _md5 后缀输出文件）
python csv_phone_to_md5.py input.csv

# 指定输出文件路径
python csv_phone_to_md5.py input.csv -o output.csv

# 仅处理第 2 列手机号
python csv_phone_to_md5.py input.csv --col 2
```

#### 高级模式参数：
```bash
# 模式：删除含手机号的行
python csv_phone_to_md5.py input.csv --mode delete_phone

# 模式：按 MD5 列去重
python csv_phone_to_md5.py input.csv --mode dedupe_md5

# 调整多进程 Worker 并发数（默认自动匹配 CPU 核心数）
python csv_phone_to_md5.py input.csv --workers 8

# 批处理块大小（默认 10000 行/块）
python csv_phone_to_md5.py input.csv --chunk-size 20000
```

## ⚡ 性能与技术特性

- **分块多进程流水线**：利用 Python `multiprocessing` 进程池并发哈希计算，充分榨干多核 CPU 算力。
- **恒定低内存开销**：基于生成器流式读写，不将整个超大文件一次性加载至内存，处理 10GB+ 文件内存占用依然稳定在 100MB 级别。
- **智能正则规整**：
  - 自动识别并清洗常见格式：`+86 138-0000-0000`、`13800000000`、`(138)00000000`。
  - 精确匹配符合大陆运营商规则的 11 位手机号 (`1[3-9]\d{9}`)。
