## 1. 基本信息与架构

- **应用名称**：李跳跳 (波妞版 2.2)
- **应用包名**：`hello.litiaotiao.app`
- **核心服务**：`LttService`（基于 Android 无障碍服务 AccessibilityService 实现）
- **加固特征**：腾讯乐固企业版加固
  - 核心逻辑加密存放于 `assets/0OO00l111l1l`
  - 引导入口为 `com.tencent.StubShell.TxAppEntry`
  - 动态链接库 `libshell-super.2019.so` 负责在 Application 启动阶段将原 Dex 映射进内存。

## 2. 日常使用：导入 177+ 最新聚合规则

当前项目已内置社区持续维护并经过校验的最新规则库文件：
👉 **`李跳跳规则_AllRules.json`**

### 详细导入步骤：
1. **传输文件**：将 `李跳跳规则_AllRules.json` 传送到手机微信、QQ 或存储根目录。
2. **复制内容**：
   - 推荐使用手机自带文本阅读器或 **MT 管理器** 打开该文件。
   - **全选** 并点击 **复制**（切勿使用容易截断长文本的第三方输入法中转剪贴板）。
3. **打开李跳跳 App**：
   - 点击主界面下方的 **「更多」**。
   - 点击右上角菜单按钮（三个点）。
   - 在弹出的菜单中选择 **「导入规则」**。
4. **粘贴规则**：
   - 长按文本输入区域，选择 **「粘贴」**。
   - 点击 **「保存」**。
5. **验证成功**：
   - 界面弹出提示：“成功导入规则”即可生效。

> ⚠️ **注意**：每次导入规则为**全量覆盖**机制，导入新规则会替代旧规则。

## 3. 防杀后台系统设置指南

为保证开屏跳过稳定运行，请确保完成以下系统权限设置：

1. **无障碍权限**：设置 → 无障碍（已下载的应用）→ 找到「李跳跳」并开启。
2. **电池优化白名单**：设置 → 电池/应用管理 → 李跳跳 → 省电策略选择“无限制” / “允许后台高耗电”。
3. **自启动与关联启动**：应用详情中开启“自启动”和“后台弹出界面”权限。
4. **后台任务卡片加锁**：打开多任务后台视图，在李跳跳卡片上下拉加锁，防止被系统清理。

## 4. 高级开发：脱壳与重打包工作流

若需修改 `LttService` 的点击延时、控件遍历深度或适配复杂弹窗，需遵循以下脱壳重打包流程：

### 4.1 脱壳（两种方案）
- **方案 A（推荐，手机 MT 管理器脱壳）**：
  1. 手机安装并激活李跳跳；
  2. 打开 MT 管理器 → 提取安装包 → 选择李跳跳 → 点击“功能” → “Dex 修复 / 脱壳”；
  3. 导出脱壳后的 `classes.dex` 并传回本机。
- **方案 B（模拟器 + Frida Dump）**：
  使用带有 Root 权限的 Android 模拟器，在启动时挂钩 `libshell-super.so` 内存映射完成 dump。

### 4.2 反编译与重打包
本机 `_tools/` 目录已配齐完整编译环境：

```powershell
# 1. 反编译
& "D:\devloop-tools\jdk-17.0.12\bin\java.exe" -jar _tools\apktool.jar d base.apk -o decode -f -p _tools\framework

# 2. 替换脱壳后的 Dex / Smali 并修改代码

# 3. 重新打包
& "D:\devloop-tools\jdk-17.0.12\bin\java.exe" -jar _tools\apktool.jar b decode -o _build\unsigned.apk -p _tools\framework

# 4. 重新签名 (v1 + v2 + v3 全兼容)
& "D:\devloop-tools\jdk-17.0.12\bin\java.exe" -jar _tools\uber-apk-signer.jar --apks _build\unsigned.apk --out _out
```

## 5. 常见问题与排错

- **Q：导入规则时提示“JSON 格式错误”怎么办？**  
  A：通常是因为复制时格式被输入法截断。请使用 MT 管理器或手机 WPS 打开并全选复制。
- **Q：无障碍经常被系统自动关闭？**  
  A：部分国产定制系统（MIUI/HyperOS、OriginOS、ColorOS）在内存紧张时会强制重置无障碍服务，请务必参照第 3 节开启“自启动”并在最近任务卡片“加锁”。
